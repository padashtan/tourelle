Rétro-ingénierie · Windows 11 · open source

Une webcam motorisée de 2008,
ressuscitée en direct sous Windows 11

La vidéo marchait encore sous Windows 11, mais plus aucun logiciel ne savait tourner la tête. Voici comment on lui a rendu ses moteurs.

1

Le symptôme

Windows 11 charge son pilote générique UVC : image OK, moteurs inaccessibles. Le pilote d'origine n'existe plus.

2

L'indice : une unité moteur cachée

Le descripteur USB brut déclare bien l'unité moteur… avec un type propriétaire 0x41 au lieu du standard 0x24. Le pilote Windows l'ignore.

20 41 01 09  82 06 61 63 … 5E 8D 22 56  05 01 04 03 1F
3

Le contournement : réécrire le pilote, en mode utilisateur

WinUSB prend la fonction vidéo. On refait le travail du pilote : négociation UVC, streaming isochrone, reconstruction des images. Aucun pilote noyau, aucune signature, Secure Boot intact.

4

Le retour dans toutes les applis

Une caméra virtuelle Windows 11 (Media Foundation, Frame Server) republie l'image. Teams, Zoom ou OBS la voient, et la tête se pilote pendant l'appel.
